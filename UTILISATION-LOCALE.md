# Utilisation locale

Pour une première installation, suivre le README : compiler Java, installer et lancer l'interface, ouvrir l'accueil. Une base vide est créée automatiquement ; aucun mot de passe n'est demandé.

Après compilation des deux services et création de la base, `DEMARRER-WINDOWS.cmd` les lance ensemble. Ne pas laisser une autre instance sur les ports 8082 et 3102. Ctrl+C arrête le lanceur.

Choisir GM ou joueur dans « Vue affichée ». Le choix est conservé par onglet. Les profils de campagne sont publics ; la démo `/?demo=1` utilise un état local fictif.
