# Contrôle de la distribution — 28 octobre 2026

Cette distribution a été reconstruite dans un dossier indépendant à partir des seules sources sélectionnées pour le partage.

- Java : wrapper Maven, 6 360 tests réussis, JAR construit.
- Interface : installation neuve avec `npm ci`, 51 tests réussis, formatage, TypeScript et compilation Next.js réussis.
- Aucun historique Git du dossier de travail n'est repris ; aucune publication distante n'a été effectuée.
- Les chemins sélectionnés excluent les bases de données, sauvegardes, exports, journaux, configurations privées et anciens dossiers de travail.
- Une comparaison locale avec les anciens secrets disponibles n'a retrouvé aucun mot de passe réel ni empreinte privée dans ces fichiers. Les valeurs scrypt des fixtures de tests sont fictives.
- Les dépendances installées et résultats de compilation ne sont pas inclus dans le ZIP.

Le contrôle ne constitue pas une garantie absolue d'absence de vulnérabilité. L'exécution du workflow sur GitHub et le déploiement macOS restent à confirmer. Le site livré est volontairement en accès libre, y compris la sélection du GM.
